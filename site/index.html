One installation, two agents

A skill that teaches agents to show their work.

muckdb gives Claude and Codex a disciplined visual-analysis workflow: create durable views, format values, post charts with captions, and leave a dashboard the human can probe instead of a wall of claimed numbers.

For CodexUse SQL as usual; present the result as a session dashboard.
For ClaudeThe installed skill is linked into Claude’s skill directory automatically.
For peopleOpen one localhost URL to filter, explore, or export the source data.
For handoffsSession context preserves sources, caveats, and decisions.

Install the visual skill

$ muckdb skill install
# writes ~/.agents/skills/muckdb
# links it into ~/.claude automatically

Start a new Claude or Codex session after installation. The skill guides the agent from raw data to a readable, interactive report.

Install & update

Get the binary. Teach the agent. Keep it current.

Install once, then give your agent the visual-analysis skill. muckdb keeps an eye on new releases too, so you always know when an update is available.

01 / INSTALL

Install muckdb

Choose your platform below. Each install path also enables the skill for Claude and Codex.

muckdb --version muckdb --display
02 / ENABLE

Install the skill

The platform commands include this step. Start a fresh agent session after it completes.

muckdb skill install
03 / USE

Ask your agent

Inside Claude or Codex, ask for the analysis you need—muckdb gives the result a visual surface.

“Graph the data from the logs with muckdb.”

macOS

Homebrew

Install the published binary, then enable the visual skill for Claude and Codex.

brew install nickkaltner/muckdb/muckdb muckdb skill install

Update to the newest release, restart the local console, and refresh the installed skill:

brew update brew upgrade muckdb -y muckdb --stop muckdb start muckdb skill install -f

Linux

x86_64

Download the current GitHub release into ~/.local/bin, then enable the visual skill.

VERSION=$(curl -fsSL https://api.github.com/repos/nickkaltner/muckdb/releases/latest | sed -n 's/.*"tag_name": "v\([^"]*\)".*/\1/p') curl -fL -o /tmp/muckdb.tgz "https://github.com/nickkaltner/muckdb/releases/download/v$VERSION/muckdb-$VERSION-x86_64-unknown-linux-gnu.tar.gz" tar -xzf /tmp/muckdb.tgz -C /tmp install -Dm755 /tmp/muckdb ~/.local/bin/muckdb muckdb skill install

Update by running the same download commands again, then restart and refresh the skill:

muckdb --stop muckdb start muckdb skill install -f
